# design-pal-codex

面向电脑端工具类产品的组件库设计与交互预览项目。

**当前为开发版：交互样稿与首批可复用基础组件。** 按钮、单行输入和详情容器已有独立挂载、更新及卸载入口；完整组件目录、Claude Code／Codex 技能安装、项目采用与版本恢复仍在开发，不能把当前内容当成首版组件库已完成。

## 已有内容

- 规整、松弛、棱角三套设计方向；每套两种配色，均支持亮暗模式。
- 组件库首页、配色轮播、产品类型筛选和库详情。
- 表单、数据表格与筛选、导航、指标图表、弹层和反馈等交互示例。
- 同一内容下的不同布局、详情方式、图标及动效；组件状态并列展示。

所有项目、人员和指标均为虚构演示数据。文件选择只显示文件名，不上传或读取文件内容；复制、导出等菜单只展示反馈，不连接真实业务服务。

## 基础组件与原交互样稿

基础组件的运行、测试和使用方法见 [组件用法](USAGE.md)。构建后可查看三套库各两个独立实例，验证切色、输入、详情与操作反馈；该验证页不替代完整样稿。

## 原样稿本地运行

下载仓库后，直接打开 `examples/preview/index.html`，或使用 Python 3 启动本地预览：

```sh
python3 -m http.server 8765 --bind 127.0.0.1 --directory examples/preview
```

然后访问 <http://127.0.0.1:8765/>。静态预览无需安装依赖，也不调用远程图标服务。

## 测试

使用 Node.js 24 运行状态、配色、构建与本地服务测试：

```sh
npm test
```

使用 `npm ci` 与 `npx playwright install chromium` 安装开发依赖和浏览器后，可运行 `npm run test:browser` 检查基础组件与样稿规则的一致性、12 种外观、键盘和焦点行为。测试范围不等于完整组件交付或 Agent 接入验收。

## 工具名称

本项目的技能、命令和后续 Agent 能力统一使用 `design-pal-codex` 前缀，以区分其他同类项目；不会注册通用的 `design-pal` 入口。当前尚无可安装的技能，不要把仓库直接复制到技能目录。
