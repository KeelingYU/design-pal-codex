# 执行与确认边界

完整发行物同时包含资源、预览、使用说明、适用性目录、技能和采用工具；技能本身不是组件包。安装后定位信息保存在技能旁的 `release-location.json`，它属于本机配置，不进入公开发行物。移动发行目录后需要用户明确处理定位，不得静默切到最新版。

## 推荐输出

1. 业务需求及已读／未读参考。
2. 推荐库、颜色与模式，适合与不适合的原因。
3. 真实预览入口与现有能力缺口。
4. 需要用户确认的具体采用计划；未确认时明确尚未写入目标项目。

无法读取参考时，可以基于已有文字给临时建议，但说明建议依据不足，不能声称忠实复现。用户要求同时使用两套同类工具时先澄清各自职责，不能覆盖任意一套。

## 采用命令

先读取完整发行物的 `PROJECT.md`，以其中经验证的参数为准：

```sh
node <发行目录>/scripts/project.mjs plan-adopt <发行目录> <已有目标项目> <library> <color> <light|dark>
node <发行目录>/scripts/project.mjs adopt <发行目录> <已有目标项目> <library> <color> <light|dark> <已确认计划摘要>
```

第二条仅在用户确认第一条显示的具体计划后运行。先确认项目当前采用状态；已有采用目录不得再次覆盖安装。

## 数据与复现

预览数据为虚构示例，不能证明业务接入。现有项目先在隔离副本验证业务操作，在有明确目标和授权后改真实项目。界面复现需固定窗口、字体、内容、状态及版本，分别检查外观与操作。任何未登录、额度不足、缺少读取工具、宿主失败都记录为未验证，不编造对话、截图或测试通过。
